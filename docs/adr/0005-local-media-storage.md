# ADR 0005 — 生成结果本地存储

## 状态

已接受 — 2026-07-03

## 背景

上游 AI 服务返回的图片/视频 URL 通常有时效性（几分钟到几小时不等），不适合直接作为资产引用。节点间通过 `@` 引用上游输出时，引用的是一个过期链接会导致断链。

## 决策

- 后端收到上游返回的结果后，将资源下载到本地文件系统
- 返回给前端的 URL 指向本地后端服务（如 `/api/media/xxx.png`）
- 静态资源通过 FastAPI 的 `StaticFiles` 或独立路由提供
- 生成任务的 `result` 中包含本地 URL 列表

## 存储方案

```
backend/
  media/
    images/       # 生成图片
    videos/       # 生成视频
    texts/        # 生成文本
```

## 影响

- 后端需要增加 `StaticFiles` 挂载或文件服务路由
- 需要清理策略（保留时长 / 磁盘空间限制），MVP 阶段暂不做自动清理
- 节点引用资产时始终指向本地 URL，不受上游时效限制
