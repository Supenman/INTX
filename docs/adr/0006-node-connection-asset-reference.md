# ADR 0006 — 节点连接与 `@` 引用资产

## 状态

已接受 — 2026-07-03

## 背景

画布中节点间的连接线应该传递数据。例如 TextNode（输出一段 prompt）→ ImageNode（用这段 prompt 生图）。用户需要在目标节点的输入中引用上游节点的输出。

## 决策

- 节点连接后，在 prompt 输入框中输入 `@` 触发引用菜单
- 引用菜单列出上游节点（通过连接线可达）的历史输出
- 选择后插入引用标记，如 `@node_id:index`
- 提交生成时，前端解析引用标记，替换为实际内容后发送到后端
- 连接关系由 React Flow 管理（edges 数组）
- 节点的运行顺序由连接拓扑决定：上游必须先于下游执行（阶段一暂不强制拓扑排序，用户手动点击上游运行）

## 影响

- ImageNode / TextNode / VideoNode 都需要支持引用解析
- BaseNode 可能需要增加 `outputs` 或 `images` 字段来暴露历史结果
- 引用菜单需要在 NodeDrawer 中实现，或作为独立组件
- prompt 替换逻辑放在前端（提交前完成），后端不感知引用语法
