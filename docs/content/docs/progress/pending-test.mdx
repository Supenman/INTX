# Pending Tests

## Generation lifecycle with a mock provider

- Point a channel at a local mock that streams SSE deltas. Click Generate: the primary button should become Stop and the node should fill in progressively.
- Press Stop and confirm: the button returns to Generate and the request is closed on the server side (the mock logs `client closed`).
- The text streamed before the stop must stay in the node, with "Stopped; only the content received before stopping was kept" underneath. No further deltas should be appended and the node must not flip to "Generation failed".
- Reopening the panel in that state still shows the prompt, so it can be edited and sent again; clicking Generate starts a fresh stream.
- Switch the mock to return HTTP 502: the node shows "Generation failed" with a Retry button and the upstream message, then switching the mock back and clicking Retry should complete normally.

## Generate without a configured channel

- With no API key configured, press Enter or click Generate: a "Complete the configuration first" toast should appear together with the configuration dialog, instead of the dialog alone.
- After filling in a working channel, the same action should start generation and the primary button should switch to the stop state.

## Reference order and numbering

- Connect two images to one node and select it: the thumbnails should carry 1 and 2 badges in connection order, and a single reference should show no badge.
- Run an image edit and check that the prompt prefix "reference image numbers: 图片1、图片2" matches those badges.
- Hover the first thumbnail and click "Move reference later": both badges should swap, and the prompt numbering should swap with them.
- Connect two text nodes as references: badges 1 and 2 should correspond to 【文本 1】 and 【文本 2】 in the prompt.
- In video reference mode the first two images already carry "first frame / last frame"; no numeric badge is added there, the role label wins.

## Required workflow fields

- Pick a workflow model that declares a required field (e.g. negative prompt) and press Generate without filling it: the reference status area names the missing field, Generate is rejected with the same message, and no task is created.
- The "Workflow parameters · N changed" summary counts only fields the current workflow declares; switching to another model clears the summary and values, and switching back restores them.
- Field coverage: number, text and boolean controls follow the workflow declaration, media inputs read "Input 1: required/optional", and the popover stays inside the viewport.

## Escape while an overlay is open

- With a node selected (prompt panel open), open "Generation history" from the top bar and press Escape to close it: the node stays selected and the panel stays open, no re-click needed.
- Close the "Shortcuts" modal with Escape the same way: the prompt panel should still be there.
- Open the canvas menu from the top bar and press Escape: only the menu closes, selection and panel are untouched.
- Open a node's settings popover and press Escape: only the popover closes, the panel stays.
- After all overlays are closed, pressing Escape on empty canvas should still clear the selection and collapse the panel.

## Node toolbar vs. settings popovers

- With an image, video or audio node that has content, hover the node: the floating toolbar appears. Open its settings popover: the toolbar hides. Close it with Esc: the toolbar comes back once the pointer returns to the node (the pointer sits on the panel button, so it will not reappear immediately).
- With the popover open, click another node, then click empty canvas: no stale "popover open" state should keep the toolbar hidden on the next node.
- The settings button reads back its current values to screen readers ("Image settings: Auto · 1:1 · 3 images"), matching the visible label, for all four node types.
- With nothing selected or hovered, the resize handles are not mounted, and hidden connection ports are skipped by Tab (they only take focus while hovered, selected or connecting).

## Node locking

- Right-click any node: the menu shows "Lock node". After locking, a lock badge appears in the top-right corner, the four resize handles disappear, and dragging the node no longer moves it.
- A locked node can still be selected and opened for editing; changing parameters and regenerating should work, and copy/delete stay available.
- Right-click again: the menu now shows "Unlock node". Unlocking restores the handles and dragging.
- With a node selected, press `Ctrl/Cmd+L` to toggle locking; `Ctrl/Cmd+Z` undoes it.
- Select two nodes, right-click and lock: the whole selection should switch together. Dragging moves only unlocked nodes.
- Reopen the canvas after saving: the lock badge should persist and dragging should still be blocked.

- While dragging nodes, check that connections, selection outlines, and the composer follow. Press Escape or switch windows to restore original positions. Check undo after a normal drop. Focus a selection of distant nodes and check that they all come into view and remain selected.

- While dragging a node resize handle, switch windows and release outside the app. On return, the toolbar and composer should reappear and pointer movement should no longer resize the node. Right-clicking a resize handle should not start resizing.

- Open a canvas, node, or connection context menu and check that the first enabled command is focused. Press Enter to run it or Escape to dismiss the menu, then check that focus returns to the original control or canvas. Right-click inside a multi-selection and check that copy and delete act on the entire selection.

- Hover a versioned image node. Check that the preview has no version badge or download button and that both actions are available in the node toolbar.

## Canvas connections and viewport

- Use Canvas Appearance → Fit all content with nodes spread across the canvas. All nodes should fit with margin; using it on an empty canvas should leave the viewport unchanged. After a box selection, release the mouse and confirm the hit nodes stay selected. Interrupt a box selection by switching windows or triggering pointer cancellation; verify the selection returns to its state before the drag.
- Check box selection with each modifier: no modifier replaces the selection, Shift adds hits, Alt removes hits, and Ctrl/Cmd toggles hits. Move the box repeatedly over the same nodes to confirm toggle does not flicker; interrupt each mode and confirm the initial selection is restored.
- Start a background pan without moving and release normally; selection should clear. Repeat, then cancel the pointer instead; the existing selection should remain. During a pan, an unrelated pointer ending should not stop the active gesture.
- Check locked nodes: clicking selects the node and opens its panel, dragging it does not move it, and dragging another node in a mixed selection moves only unlocked nodes.
- Tab to either port and press Enter or Space to open the creation menu. Use the arrow keys and Enter to create a connected node. Escape should return focus to the original port. While dragging a connection, Escape should keep the current selection. Delete should leave canvas nodes alone while a canvas menu is open.
- Release a connection near its target and check that the curve keeps its shape. An input port should not snap to a plugin node with its output port hidden.

- Drag near two adjacent ports from outside their nodes. The preview and drop should choose the nearest available port. Dropping on overlapping nodes should select the topmost one. Check self and duplicate connections, group outputs, and dropping on blank space to create a node.
- Scroll rapidly to zoom and check that the point under the cursor stays in place. Check panning with a horizontal trackpad gesture and Shift + wheel. Toggle the sidebar and use the zoom slider to check that it anchors to the visible canvas center.

## Canvas generation controls

- Open image, video, audio, text, and workflow settings one at a time. The node hover toolbar should hide for each open popover and return after close, outside click, Escape, or opening another settings popover.
- Tab through image, video, and audio parameter options. Keyboard focus should be visible, and assistive technology should identify the selected option.

- Drag a node, multi-selection and group. Every node moving with the selection should show a grabbing cursor and return to its resting cursor on release.
- A slight pointer movement on blank canvas should not trigger marquee selection. Drag further and check that selection works.

## Canvas settings popover tracking and reduced motion

- Open an image node's settings popover, then zoom the canvas with the wheel (or move the canvas). The popover must stay attached to the parameter button instead of staying at its original screen position.
- Shrink the window to about 1024px wide with the popover open: it should move fully above the generation panel, leaving the prompt input and the generate button visible. Content scrolls inside the popover.
- Press Esc while the popover is open: only the popover closes, focus returns to the parameter button, and the node stays selected with its generation panel still open.
- Repeat the Esc check on video, audio and text nodes.
- In the OS/browser "reduce motion" setting, page transitions and the aurora title stop moving while the "generating" spinner still turns slowly.

## Node settings popover field hierarchy

- Image node: the popover starts with a "Size" group — aspect ratio cards first, then resolution (Auto / 1k / 2k / 4k). Both write the same value, so changing either must update the trigger summary.
- Image node: below the size group there is a collapsed row "Exact size · 1024 × 1024". Expanding it reveals the W/H inputs and the "Align to multiples of 16" switch; the current pixel value stays visible when collapsed.
- Image node: change the exact size, collapse the row, and the trigger summary must match the new value; expanding again must not reset it.
- Video node: the order is "Ratio → Resolution → Exact size (collapsed) → Seconds → Mode". Picking a ratio updates the trigger summary.
- Image node: quality and transparent background sit in an "Output" group instead of being wedged between size and count.
- All four nodes (image / video / audio / text): the settings popover opens outside the generation panel and never covers the prompt input or the generate button; it stays inside the viewport on narrow screens.
- Audio node: voice, format and speed controls use the same border weight and font size as the other popovers.
- Text node: double-click the node, open "Reasoning · Auto · 1", and both "Reasoning effort" and "Count" render without clipping.

## Canvas creation entry points and node settings popover

- Press `I` / `V` / `T` / `A` on an empty canvas to create an image, video, text or audio node. The new node appears at the canvas centre and is selected; other letters do nothing.
- With the bottom `＋` create menu open, typing `t` or `i` in the search field only filters the list and must not create nodes behind it. The shortcuts work again once the menu closes.
- Each base node in the create menu shows its `T` / `I` / `V` / `A` hint on the right, matching the keys that actually work.
- Right-clicking empty canvas lists "Add node / Upload here / Insert from assets / Undo / Redo / Paste here". Undo and Redo are greyed out when unavailable but stay in the list.
- Move through the context menu with ↑↓ and Home/End, run with Enter, close with Esc and return focus to the canvas. "Add node" opens the create menu.
- Select an image node and click the parameter button in the generation panel (e.g. "Auto · 1:1 · 3"). The settings popover must appear directly above that button, left-aligned with it, not in the top-right corner of the canvas.
- When the popover is taller than the available space it scrolls to the end, and the last "Count" row stays fully readable.
- Zoom the canvas out to 25% and open the settings popover: it stays fully inside the viewport, sits beside the generation panel, and does not cover the prompt input or the generate button.

## INTX 2.2a-1：任务异步存储（待用户验收）

- 任务台账仍使用当前 IndexedDB 的 `app_state` 和原任务键；首次读取当前 JSON 快照不改写，首次成功写入补版本元数据，既有任务/顺序/引用保留，不删除旧库。
