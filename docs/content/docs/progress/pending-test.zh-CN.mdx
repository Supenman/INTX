# 待测试

## 共用生成输入区与参数选中反馈

- 分别在图片、视频、音频和文本节点上上下拖动输入框底部中央的手柄；输入区应调整高度，不应带动节点或触发画布手势。聚焦手柄后用方向键和 Home/End 检查键盘调整。
- 在收起的生成面板里调整字号，切换节点类型并打开编辑器；字号应保持且应用到提示词和占位文字。重启应用后确认字号偏好仍保留。
- 单独调整展开编辑器高度，关闭后再打开；确认收起输入区高度不变。
- 打开适用的图像、视频、音频、文本和工作流参数面板；确认选中项有清晰柔和的填充，入口能反馈开合状态，修改设置仍同步摘要和生成请求。
- 在窄窗口和浅色主题下重复检查；确认调整手柄可操作，设置控件不会挤压或遮住「生成」按钮。

## 用假接口验收生成全流程

- 把渠道指向本地假接口（按 SSE 逐块返回）。点「生成」：主按钮应变为「停止」，节点内容逐块出现。
- 点「停止」并确认：按钮回到「生成」，服务端能看到连接被关闭（假接口侧记录 `client closed`）。
- 停止时已经流出来的文本要留在节点里，正文下方有一行「已停止，只保留了停止前收到的内容」；停止之后不会再有新字追加进来，节点也不会变成「生成失败」。
- 在这个状态下重新打开面板，提示词还在，可以改完再发；点「生成」会重新开始一条流。
- 把假接口切成返回 502：节点显示「生成失败」和「重试」，并带上上游错误信息；切回正常后点「重试」应正常完成。

## 未配置渠道时触发生成

- 没填 API Key 时按 Enter 或点「生成」：应同时出现「请先完成配置」提示和配置窗口，而不是只弹窗口。
- 配置好可用渠道后再点生成，应进入生成中，主按钮切换为停止。

## 参考素材的顺序与编号

- 把一张图片连到节点：缩略图应显示 1 角标，与「图片1」参考标签一致；再连第二张时，1、2 应按连线顺序排列。
- 生成一次图生图，核对请求里的提示词前缀「参考图片编号：图片1、图片2」与缩略图角标对得上。
- 悬停第一个缩略图，点「后移参考素材」：两个缩略图的角标应互换，提示词编号也随之互换。
- 连一个文本节点作为参考：缩略图 1 角标应对应【文本 1】；连两个时，角标应与【文本 1】【文本 2】顺序一致。
- 视频节点的首尾帧模式里连一张图：缩略图只标「首帧」，没有数字角标。
- 连两张图：分别标「首帧」「尾帧」，数字角标不叠加（角色标签已经说明了顺序）。
- 连三张图：首尾帧不再适用，标签消失，改为左上角的 1、2、3，顺序与连线顺序一致。

## 连线手势取消

- 框选时让另一根手指或笔触发松开/取消，框选应继续；启动框选的指针松开才提交，取消或失焦才恢复起始选区。
- 从输出端口开始连线时，只显示该起点和当前合法目标的输入端口；从输入端口开始时检查两侧相反。悬停或选中的节点仍保留原有端口显示。
- 从节点端口拖出连线后，取消另一个指针（例如第二根手指的手势），原连线预览应继续保留。
- 使用触摸指针（若设备支持）拖线到合法目标和空白处，确认分别完成连接和打开创建菜单；移动、松开只响应启动连线的指针。
- 取消启动连线的指针后，预览应关闭；切换窗口失焦时也应清理未完成的连线。

## 框选修饰键与触摸拖动

- 切到「移动」工具，先点选一个节点，再按住 Ctrl 框选它：应取消选中；保持未选中时 Ctrl 框选：应加选。Shift 框选为加选，Alt 框选为移除，不按修饰键为替换。
- 按住空格拖动空白处应平移画布，中键拖动同样平移；松开空格后恢复当前工具。Ctrl 不再临时切到抓手。
- 触摸设备上按住节点标题拖动，节点应跟随手指移动，不会在刚开始拖动时被系统判成滚动而中断；移动工具下触摸空白处拖动应平移画布。
- 在提示词输入框内上下滑动手指，应滚动文本而不是拖动节点或画布。

## 工具菜单（移动 / 抓手工具）

- 刚进画布时，底部工具栏的工具按钮应是箭头图标，空白处拖动应出现框选矩形而不是移动画布；点空白处单点节点应能选中。
- 点这个工具按钮：上方弹出两项「移动 / 抓手工具」，各带一行说明；当前工具那项有实心高亮和勾选。点「抓手工具」后菜单关闭、按钮变成手形，空白处拖动应平移画布。
- 菜单开着时按 Esc：菜单关闭，焦点回到工具按钮；再按 Enter 能重新打开，再按 Enter 关闭。点菜单外面也会收起。
- 菜单开着时点「画布外观」：外观面板打开、工具菜单收起（两者互斥）。
- 快捷键弹窗里应写作「Space + 拖动 · 临时切换移动 / 抓手工具」，不再提 Ctrl。

## 双指缩放

- 触摸屏上在空白处用两指捏合或张开：画布应以两指中点为锚点缩放，页面不应跟着滚动。
- 单指按住节点开始拖动后再落下第二根手指：节点应回到拖动前的位置，手势改为缩放；用同样方式打断框选时，选中项应恢复到框选开始前。
- 双指缩放后抬起一根手指，继续用剩下那根拖动：画布应跟随平移，当前选中不应被取消。
- 在提示词输入框内双指操作应保留原生文本滚动，不触发画布缩放。
- 再用触控笔或触控板驱动的触摸序列复测一次；Windows 触摸硬件仍待验收。

## 减少动态效果

- 在系统里打开「减少动态效果」（Windows：设置 → 辅助功能 → 视觉效果 → 动画效果；macOS：辅助功能 → 显示 → 减少动态效果），刷新画布。
- 用分镜流水线或批量生成一次得到多个节点：所有节点应在同一瞬间出现，不能有先来后到的错峰淡入；排在后面的节点也不应出现「空白一小会儿才冒出来」。
- 生成中按钮旁的转圈仍在慢速旋转（约 2.4s 一圈）：这是状态信息，停掉会让用户以为卡死。
- 按钮 hover、设置浮层开合、侧栏展开应收尾于瞬间，没有 0.2–0.3s 的过渡。
- 关掉该选项后刷新：错峰淡入、正常速度的转圈和过渡都应恢复。

## 矮窗口里的参数浮层

- 把窗口高度缩到应用最小值 640，选中一个生成面板位置偏低的节点，依次打开图片、视频、音频、文本设置以及工作流参数：下方空间明显更多时浮层应在面板之下展开，整体留在窗口内，并且不遮挡提示词输入框与生成按钮。
- 在常规尺寸窗口再打开同样的浮层：仍应贴在按钮右侧向上展开，不出现每次渲染来回翻面。
- 浮层打开期间调整窗口大小或缩放画布：浮层应跟随按钮移动，并保持已选择的方向。

## 工作流参数的必填项

- 用一个声明了必填字段（如负面提示词）的工作流模型，不填该字段直接点「生成」：面板参考状态区写明「「负面提示词」必填…」，点生成会被拦下并弹出同样的提示，不会创建任务。
- 工具提示里的「工作流参数 · N 项已调整」只统计当前工作流声明的字段；切到另一个模型后摘要与填值清空，切回来原填写还在。
- 浮层字段覆盖：数字、文本、布尔三类控件分别按工作流声明出现，媒体输入写成「输入 1: 必填/可选」，浮层不超出视口。
- 音频和文本节点选择 ComfyUI 工作流模型后，打开「工作流参数」，确认字段可编辑；连接工作流声明的必填图片/视频/音频输入后，对应要求应满足，断开后生成应再次被拦截。
- 工作流声明必填音频时，连接音频节点，确认面板显示已满足；提示词与其他必填项齐备后应允许提交。
- 修改一个有默认值的工作流参数后，再将其恢复为声明的默认值；摘要中的“已调整”计数应减少，不应把等于默认值的字段算作覆盖。

## 浮层打开时的 Esc

- 选中一个节点（生成面板开着），点顶栏「生成历史」，按 Esc 关闭：节点仍保持选中，面板还在，不需要重新点节点。
- 同样用 Esc 关「快捷键」弹窗：节点面板应仍然在。
- 点顶栏「打开画布菜单」后按 Esc：只关菜单，选中节点与面板不受影响。
- 打开节点的参数设置浮层后按 Esc：只关浮层，面板仍在。
- 以上浮层都关掉之后，在空白处按 Esc 仍应清空选中、收起面板。

## 设置浮层的键盘操作

- 用 Tab 走到节点的参数按钮（如「视频设置: …」），按 Enter 打开：焦点应进入浮层，再按 Tab 依次走过浮层内的选项，不会跳到画布工具栏。
- 同一操作打开后按 Esc：浮层关闭，焦点回到那个参数按钮，再按一次 Tab 应继续往后走，而不是从页面开头重来。
- 用鼠标点开同一个浮层：焦点仍留在按钮上（不强制跳进浮层），浮层可以用鼠标正常操作。
- 打开读屏软件后触发参数按钮：应读到「视频设置」这类对话框名，而不是一片没有名字的容器。
- 图片、视频、音频、文本四类参数浮层和工作流参数浮层都要走一遍。

## 焦点归属

- 打开「添加节点」菜单，用 Esc 关掉：焦点应回到画布（按 Tab 继续走画布里的工具），不会从顶栏第一个按钮重来。
- 在同一个菜单里点「文本」建节点：新节点应立刻拿到焦点，按 Tab 直接进它的面板；随后再按 T / V / A 仍能继续建节点。
- 打开生成历史，用 ✕ 或 Esc 关闭：焦点同样回到画布。
- 先生成一段内容，再打开生成历史，点其中一条的「定位」：画布应移到该节点、选中它并打开生成面板，焦点也在节点上（读屏会念节点标题），继续按 Tab 应从节点内部的按钮往下走，而不是回到页面开头。
- 在版本对比里点某个版本的定位按钮，表现应一致。
- 定位后直接按 Esc：清空选中、面板收起，节点本身留在原处。
- 用鼠标点节点空白处：提示词草稿和生成面板都不应受影响，只是焦点移到节点上。

## 生成失败与图片工具弹窗

- 让渠道返回 5xx（或断网）生成一段文本：节点和面板里应显示上游的具体错误（例如 502），而不是只有「生成失败」，也不应出现两行完全相同的文案。
- 图片批量生成全部失败时，节点应显示第一条真实错误；部分失败时仍保留单张的重试按钮。
- 悬停有图片的节点，点工具栏最右的「配置快捷工具」：弹窗应稳定停留，不会一闪而过；取消勾选一个工具后保存，工具栏按钮应立即减少。
- 弹窗开着时把鼠标移到画布空白处再按 Esc：弹窗关闭，悬浮栏不应一直挂在节点上；用 ✕ 或保存关闭时，焦点应回到「配置快捷工具」按钮或画布里的节点，不落到页面开头。
- 依次打开节点信息、裁剪、切图、放大、超分、多角度、预设、版本对比，用 Esc / ✕ 关闭后按 Tab：焦点应在画布里继续，而不是从顶栏第一个按钮开始。

## 读屏名称

- 打开读屏软件（Windows 讲述人 / macOS VoiceOver），在画布提示词框上停留：应念出「描述要生成的图片/视频/文本内容」这类名称，而不是只念「编辑框」。
- 视频设置里用键盘走到时长滑块和秒数输入、音频设置里的语速、图片设置里的生成张数与「16 倍数对齐」「透明背景」开关：都应念出对应名称。
- 用 axe DevTools 或同类工具扫画布、四类设置浮层、工作流参数浮层、生成历史、快捷键弹窗和展开编辑器：不应再出现 critical 或 serious 级违规。
- 画布生成面板底部的模型选择器、画布「更多」菜单里的配置对话框 → 偏好设置：前进到模型和生成默认值下拉，读屏应念出「选择模型 · gpt-5.5（默认渠道）」「默认生图分辨率 · 自动」这类标签加当前值，而不是只念模型名或干脆没有名称。

## 节点悬浮工具栏与设置浮层

- 图片、视频、音频节点有内容时悬停，悬浮工具栏出现；点开它的参数浮层后工具栏隐藏；按 Esc 关闭后把鼠标移回节点，工具栏恢复（鼠标停在面板按钮上时不会立刻出现）。
- 浮层打开时点另一个节点、再点空白，确认不会残留「浮层已打开」状态导致下一个节点的工具栏一直不出现。
- 四类节点的参数按钮，读屏读到的应是「图像设置: 自动 · 1:1 · 3 张」这样的标题加摘要，与可见文字一致。
- 未选中、未悬停时缩放手柄不挂载；隐藏的连接端口不在 Tab 顺序里（只在悬停、选中或连线时可聚焦）。

## 节点锁定

- 右键任意节点，菜单出现「锁定节点」；点击后节点右上角显示锁标记，四角缩放手柄消失，拖动节点位置不变。
- 锁定状态下点节点仍能选中并打开生成面板，改参数后重新生成正常；节点仍可复制、删除。
- 再次右键显示「解锁节点」，解锁后手柄和拖动恢复。
- 选中节点按 `Ctrl/Cmd+L` 切换锁定；锁定后按 `Ctrl/Cmd+Z` 能撤销回未锁定。
- 多选两个节点后右键「锁定节点」，确认整组一起切换；拖动时未锁定节点正常移动，再次全选拖动时全部跟随。
- 锁定状态保存后重新打开画布，锁标记仍在，拖动仍被阻止。

- 拖动节点时检查连线、选区轮廓和生成面板跟随。按 Esc 或切换窗口应恢复原位。正常松手后检查撤销。多选相距较远的节点并点击「居中聚焦」，确认整个选区入镜且保持多选。

- 拖节点角落调整尺寸时切换窗口，在外部松开再返回。工具栏和生成面板应恢复，移动鼠标时节点尺寸保持不变。右键按下缩放手柄不应开始调整。
- 调整尺寸时取消另一个指针，当前缩放应继续；只有启动缩放的指针松开或取消才结束。

- 打开画布空白、节点或连线的右键菜单，确认第一条可用命令获得焦点。按 Enter 执行或按 Esc 取消后，焦点回到原控件或画布。多选时右键选区内的节点，确认复制和删除针对整组选区。

- 悬停有版本的图片节点，确认图面没有版本徽标和下载按钮，工具栏仍能下载及打开节点版本对比。

## 画布连线与视口

- 在画布外观菜单点「适配全部内容」，确认分散在画布各处的节点都完整进入当前视口并保留边距；空画布执行后视口不变。框选节点后松开鼠标，确认命中的节点仍保持选中；拖动中切换窗口或触发指针取消，确认选区恢复到拖动前状态。
- 分别测试框选修饰键：无修饰键替换选区，Shift 添加，Alt 移除，Ctrl/Cmd 切换命中节点。框选反复扫过相同节点时确认切换结果不闪烁；分别中断各模式，确认恢复拖动前的选择。
- 在画布空白处开始平移但不移动，正常松开应清除选中；再重复并取消指针，原选区应保留。平移过程中结束另一个指针，当前平移不应提前停止。
- 测试锁定节点：点击仍可选中并打开面板，拖动锁定节点时位置不变；混合选区拖动其他节点时，锁定节点留在原位。
- 用 Tab 聚焦节点左右端口，分别用 Enter / 空格打开菜单，再用方向键和 Enter 创建相连节点。按 Esc 关闭菜单时，焦点应回到原端口。鼠标拖线时按 Esc 应只取消连线，保留节点选中。菜单打开时按 Delete 不应删除画布节点。
- 在离目标很近时松手连线，曲线不应突变。输入端口不会吸附到隐藏输出端口的扩展节点。

- 在两个端口靠得很近时，拖线从节点外侧靠近两者，确认预览和松手都选最近的可用端口。直接拖到重叠节点上应命中最上层。检查自身、重复连线、组输出和空白处创建节点。
- 鼠标滚轮连续缩放时，指针下的点应保持位置。用触控板横划或 Shift + 滚轮检查平移，确认普通纵向滚轮仍缩放。开合侧栏后拖动缩放滑块，检查实际画布中心保持不动。

## 画布生成面板与参数入口

- 图片、视频、音频、文本节点分别打开模型选择器与参数面板，再打开另一类浮层；应始终只显示最后打开的一个。

- 分别打开图片、视频、音频、文本和工作流设置浮层，悬浮工具栏都应隐藏；点击外部、按 Esc 或打开另一设置浮层后，工具栏状态应正确恢复。

- 开合画布侧栏和 Agent、打开并关闭生成历史，确认项目、节点选中状态和缩放保留，侧栏不覆盖画布。
- 确认顶栏显示「生成历史」，有多个版本的节点显示「查看节点版本」，弹窗标题为「节点版本对比」。

## 设置浮层跟随与减少动态效果

- 打开图片节点的设置浮层后用滚轮缩放画布（或平移画布），浮层应始终贴着参数按钮，不能停在原来的屏幕位置。
- 把窗口缩到约 1024px 宽再打开浮层：浮层应整体移到生成面板上方，提示词输入框与生成按钮保持可见，内容在浮层内滚动。
- 浮层打开时按 Esc：只关闭浮层，焦点回到参数按钮，节点保持选中、生成面板仍在。
- 视频、音频、文本节点重复上述 Esc 检查。
- 在系统/浏览器开启「减少动态效果」后，页面过渡与标题极光动画停止，生成中的旋转仍以低速转动。

## 节点设置浮层字段分层

- 图片节点：浮层顶部是「尺寸」组，先宽高比卡片、再分辨率（自动/1k/2k/4k），两者写的是同一个参数，改任一项按钮摘要都应同步变化。
- 图片节点：尺寸组下方有一行「精确尺寸 · 1024 × 1024」，默认收起；点开展开 W/H 输入框与「16 倍数对齐」开关，收起时右侧仍显示当前像素值。
- 图片节点：改完精确尺寸再收起，按钮摘要与新像素一致；重新展开时数值不回到旧值。
- 视频节点：浮层顺序为「比例 → 清晰度 → 精确尺寸（折叠）→ 秒数 → 模式」；选比例后按钮摘要同步更新。
- 图片节点的画质档位与透明背景归在「输出」组内，不再夹在尺寸与张数之间。
- 四类节点（图片 / 视频 / 音频 / 文本）打开设置浮层时，浮层落在生成面板外侧，不遮挡提示词输入框与生成按钮；屏幕宽度不足时浮层仍在视口内。
- 音频节点：声音、格式、语速三项的选中态边框与字号与其他浮层一致，不再比图片浮层粗一圈。
- 文本节点：双击节点打开面板后点「推理 · 自动 · 1 次」，「推理强度」与「生成次数」横向排布正常。

## 画布创建入口与节点设置浮层

- 画布空白处按 `I` / `V` / `T` / `A` 分别新建图片、视频、文本、音频节点，新节点出现在画布中心并处于选中态；按其它字母无反应。
- 打开底部 `＋` 添加菜单时，搜索框里输入 `t`、`i` 等字母只做搜索，不应在背后新建节点；关闭菜单后快捷键恢复。
- 添加菜单中四类基础节点右侧显示 `T` / `I` / `V` / `A` 键位提示，与上面实际生效的按键一致。
- 空白处右键依次显示「添加节点 / 上传到这里 / 从资产库插入 / 撤销 / 重做 / 粘贴到此处」，无撤销记录时撤销、重做置灰但仍在列表中。
- 右键菜单用 ↑↓、Home/End 移动焦点，Enter 执行，Esc 关闭且焦点回到画布；点「添加节点」应打开创建菜单。
- 选中图片节点后在生成面板点参数按钮（如「自动 · 1:1 · 3 张」），设置浮层应出现在该按钮正上方、与按钮左边缘对齐，不应飘到画布右上角。
- 设置浮层内容超出可用高度时应可滚动到底，最后一行「生成张数」完整可读，不被截断。
- 缩小画布到 25% 后打开设置浮层，浮层仍完整落在视口内，并排显示在生成面板一侧，不遮挡提示词输入框和生成按钮。
- 在设置浮层里改一项参数后按 Esc 关闭，焦点回到参数按钮，重新打开时值保留。

## BeefTV 画布节点交互对齐

- 在 25%、50%、100%、200% 缩放下检查节点标题字号保持稳定；非图片节点悬停/选中时长标题展开换行，离开后恢复截断；基础节点与插件节点都显示类型图标。
- 单击图片节点名称不进入重命名，双击名称或点铅笔进入编辑；Enter 保存、Esc 取消，其他节点名称仍可按原方式编辑。
- 连线未选中时以细淡线显示并在两端有小圆点；选中后线条和端点变亮、加粗。
- 拖动已选中的图片生成节点时，上方工具栏和下方生成面板应持续显示并跟随节点移动；松开后停在新位置，继续可操作。拖动其他节点时上方工具栏也应持续跟随；多选拖动不应出现单节点工具栏。
- 拖动节点时取消另一个触摸/笔指针，当前拖动应继续；只有启动拖动的指针松开或取消才结束。点击节点内按钮、编辑文本、拖连接口和缩放角点时不得误启动节点拖动或画布框选。
- 将单个节点移到画布左、右边缘及顶部附近，工具栏应完整留在视口内；拖动画布、缩放和改变窗口大小后仍应锚定节点。打开下方配置面板并改变其高度，工具栏应避开面板且保持可操作。
- 新建四类基础节点，对照默认尺寸：图片/视频 720×405、文本 350×350、音频 320×320；验证缩放图片/视频时保留比例且最小尺寸不低于 420×236。打开已有画布确认已保存节点不被自动放大或改形。
- 新建空文本、图片、视频、音频节点，确认媒体图标大而淡、文本为空时显示四条淡横线；切换浅色/深色主题后仍清晰可辨，读屏标签保留。
- 对已有图片、视频、音频的节点发起重试并制造失败，确认原媒体仍可见；左上角有失败标记，底部显示错误详情与原有重试或任务查询按钮，读屏能收到错误告警。
- 浅色/深色主题中分别单选节点、连接目标节点和关联节点：普通选中描边应使用主题的中性色，关联描边更淡，拖入组目标仍显示蓝色强调；边框宽度不应因状态切换跳动。
- 清除或移除 `canvas-side-panel-open` 偏好后新开画布，侧栏应默认收起、画布铺满可用区域；通过顶栏按钮展开和收起，再重启应用确认显式选择能恢复。
- 在深色、浅色主题分别悬停和选中节点，检查左右连接轨道只在节点可操作时出现；悬停连接轨道时圆点跟随指针，离开后回到节点边缘。
- 从左右端口单击添加节点、拖线连接已有节点、拖到空白处创建节点，确认连线方向和节点位置正确。
- 通过端口创建菜单用方向键切换节点，Home/End 定位首尾；按 Esc 或点击菜单外关闭，显式关闭时焦点应回到连接点或画布。选择节点创建后，焦点不应抢离新节点流程。
- 从底部新增按钮、画布空白处双击和右键菜单分别打开创建菜单，用 Esc 和关闭按钮退出；焦点应回到原按钮或画布。选择资源类动作打开弹窗时，焦点应进入新弹窗。
- 打开底部「外观」和「扩展节点」弹层，用 Tab 操作其中控件，按 Esc 关闭后焦点应回到对应工具栏按钮。
- 依次打开图片、视频、音频、文本节点的生成设置，面板应锚定在生成区附近；改变窗口宽度后不应横向溢出，面板内容可滚动。设置面板打开时，节点悬浮栏应避开面板并保持按钮可点；关闭设置后悬浮栏回到节点上方。
- 检查各类节点悬浮栏顺序：设置、信息、复制、删除，再显示当前节点可用的保存资产、生成/上传、下载及媒体工具；图片节点的信息、复制和删除按钮应可见；节点悬浮栏高度应与 BeefTV 紧凑工具条接近，不遮住媒体预览。
- 空文本、图片、视频、音频节点无论配置面板开合或指针悬停都不显示节点悬浮操作栏；文本节点出现正文或媒体节点有内容后，悬浮栏才显示。
- 悬停有内容的单个节点时显示悬浮栏；从节点移向悬浮栏时不能闪退，停留在工具栏上仍可点击；指针离开后约 120ms 收起。多选节点时不显示单节点悬浮栏，拖动选中节点时悬浮栏保持跟随。
- 对有内容的图片/视频节点发起再次生成，生成期间应收起节点悬浮栏，生成面板里的停止操作仍可使用；任务结束后悬浮栏恢复。

- 视频画面截取：右键有内容的视频节点应显示「截取首帧」「截取尾帧」「截取当前帧」；三项操作应按视频原始比例在右侧生成并选中图片节点，同时建立视频到图片的连线；「截取当前帧」应使用播放器此刻停留的画面，截取过程不得改变原视频的播放位置。
- 文本节点：节点正文右上角不再显示「生图」按钮，文字内容应使用完整正文区域；节点上方工具条中的生图入口应直接在该文本节点上按图片模式生成，结果落在右侧。
- 多文本生成：生成次数大于 1 时只创建一个文本结果节点和一条来源连线；节点右上角显示实际生成成功的文本数量，点击后应像多图节点一样展开所有备选文本；点击「设为主文本」应立即替换正文，原主文本保留为备选，双击正文编辑后再次切换回来仍应保留修改。
- 组节点引用：组节点应使用透明、轻量的边框与标题样式，并显示右侧输出连接点；把组连接到生成节点后，组内有内容的图片、视频、音频、文本及可引用扩展节点都应作为输入，普通提示词面板的 `@` 列表应显示组内资源，生成节点的提示词面板 `@` 列表应允许一次选择整组；组与单节点重复引用时不得重复发送同一资源。
- 多选打组：框选或点选至少两个节点后，应出现包住全部选中节点的圆角虚线框，框上方显示「打组」；点击后用组节点包住这些内容并保持原位置，随后选中该组。选中组后可通过顶部「解散组」、右键菜单或 `Ctrl/Cmd+Shift+G` 取消分组；已同属一组的节点再次多选时应显示「解散组」而不是再打一组。拖入组、组引用和左侧树形列表应继续可用。
- 节点参考栏：普通节点提示词面板和放大编辑器上方应显示当前输入节点；图片和视频显示缩略图并可悬停预览，文本、音频及扩展节点显示对应类型；组连接应展开显示组内每个有效内容节点，删除任一展开项都应断开整组连线。点击加号进入画布选择后可连续添加有效参考，已连接、目标自身、已通过组引用的组内节点及不可引用节点不可重复选择，按 ESC 或顶部提示返回输入框；新增连接后 `@` 列表应立即更新。
- 多图透明背景：展开包含透明 PNG 或 WebP 的多图节点时，主图与所有备选图的透明区域都应直接显示画布背景；切换主图前后不得出现白色或主题面板底色。
- 画布选择与平移：左下工具栏的工具按钮点开应是「移动 / 抓手工具」两项并用图标显示当前模式；移动模式拖动空白区域应显示疏朗清晰的虚线框，虚线长度、间距和粗细在任意缩放比例下保持一致，且移动模式下不能拖动画布；抓手工具模式拖动空白背景应平移画布，点节点应能选中。两种模式下点空白都应取消选中并收起节点的悬浮栏与下方生成面板。按住空格应临时反转当前工具且不改变工具栏模式，即移动变抓手工具、抓手工具变移动；点击画布页任意按钮后按空格应只临时切换工具，不得再次触发该按钮；输入框和可编辑文本内仍可正常输入空格。中键平移以及 Shift/Cmd 追加选择节点应继续可用。
- 文档站国际化：访问文档站首页及 `/docs` 应直接显示英文，不得出现重定向循环；切换简体中文后 URL 应带 `/zh-CN` 且首页、顶部导航、侧边栏、正文、搜索框和页面操作文案均显示中文；刷新、站内跳转和再次切回 English 后语言应保持正确，搜索结果与 Markdown/LLM 文档内容不得混入另一种语言。
- 国际化基础框架：从页面右上角切换简体中文或 English 后，顶部导航、版本弹窗、配置主面板、渠道编辑、模型选择、页面标题、页面描述和 Ant Design 内置文案应立即切换，刷新页面后保持所选语言；偏好设置中不应再显示语言选项，WebDAV 同步错误及其他尚未接入翻译的业务模块暂时仍可能显示中文。
- 全局弹层主题：全站 Dropdown、Menu、Select、Cascader、TreeSelect 等弹层在浅色主题下应使用白色背景、轻灰悬停和选中态，在深色主题下应使用深色背景与低对比度浅色交互态，不应再出现默认黑灰色块、文字对比不足或单个页面配色不一致。
- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。
- Agent MCP 初始化状态：首次进入空白对话、点击「新对话」或恢复历史对话后，无需先发送消息，对话区应立即显示 Agent 会话准备，并列出 `codex_apps`、`infinite-canvas`、`node_repl` 等完整 MCP 服务状态；全部服务进入终态前可输入并保留草稿，但发送按钮、上传和回车提交应禁用；可选 MCP 失败时应提示警告但允许发送，`infinite-canvas` 缺失或失败时应阻止发送并显示明确原因；首轮及后续任务运行期间再次收到的 MCP 状态只进入诊断日志，模型开始处理及回复完成后对话区不应残留初始化卡片。
- Agent 模型设置：连接 Canvas Agent 后，输入框左下方应显示当前 Agent 模型与推理强度；模型列表应来自当前账号实际可用模型且不显示内部审查模型或重复项，切换模型后强度选项随模型能力更新且无空白选项，刷新页面后保留选择，发送任务时实际使用所选模型和强度；本地控制台与右侧「日志」应记录本轮使用的模型和推理强度。
- Agent 新对话响应：一轮对话完成后点击「新对话」，聊天内容应在服务端确认切换后清空并进入空白对话；后台应串行创建线程并预热 MCP，多个标签页应按同一会话版本同步，旧 HTTP 响应不得覆盖较新的 SSE 状态，初始化完成前不能发送到上一条会话或重复创建线程；重启 Agent 后应重新恢复并预热已有活动线程，无法恢复的失效空线程应自动替换为可用的新线程。
- Agent 读取画布卡片：读取当前画布完成后，卡片应按非零类型显示文本、图片、配置、视频、音频、分组、其他节点及连线数量，例如「3 个文本、5 张图片、2 个配置、4 条连线」；空画布应显示「当前画布为空」，执行失败时仍应显示错误信息，刷新恢复历史后统计保持一致。
- Agent 首次发送响应：在空白新对话中输入内容并按回车后，输入框应立即清空、用户消息应立即出现在对话中，再显示「正在思考」；线程创建或发送失败时，原输入和附件应恢复；任务运行期间输入的新草稿不应在请求成功后被清空。
- Agent 动态工具信息：执行内置生图、查看图片、命令、文件修改或其他动态工具时，卡片标题应显示具体工具名称；执行失败时正文应显示真实错误原因，刷新并恢复历史对话后仍应保持一致，不再统一显示「工具操作已完成」。
- Agent 画布生图：重启 Canvas Agent 后，其自动生成的工作区 `AGENTS.md` 应同步为最新版指令（用户自行编写的其他 `AGENTS.md` 不应被覆盖）；输入“生成一张图片”时应调用 `canvas_generate_image`，通过当前画布节点创建并运行生成流程；只有明确输入“使用 Agent 内置生图/ImageGen 技能生成”时才允许调用内置能力，Agent App Server 返回的 `imageGeneration` 结果应显示在对话中并作为保持原比例的图片节点添加到当前画布；Agent 不应在没有生成结果时提前声称“已生成”。
- Agent 顶部栏：在对话、历史和日志之间新增「技能」标签并显示已加载数量；连接状态应位于左侧 Agent 标题旁，并与右侧新对话使用相同规格的文字按钮，只有内容标签显示选中线；标签图标始终显示，中英文模式下都应按标签区域的实际可用宽度隐藏文字并保留小号数量，空间足够时显示图标和文字，拖动宽度时不应裁切、换行、横向滚动或错位。
- Agent 输入框窄屏布局：底部上传、Skill、确认模式、权限模式、模型和思考程度控件在窄面板下应只显示图标，宽面板下恢复文字；所有纯图标操作悬停时应使用统一样式显示名称或当前状态，任意宽度都不出现横向溢出。
- Agent 本地 Skill 管理：连接 Canvas Agent 后进入「技能」，应能读取当前 Agent 工作空间发现的项目、个人、系统和管理员 Skill，并支持搜索、按范围筛选、刷新及启停；未能加载的 Skill 应通过可点击、可滚动的详情查看原因；画布在站点工作空间 `.agents/skills` 下创建的 Skill 应可新建、编辑和删除，其他来源只读且不得被画布改写；编辑期间文件被其他窗口修改时应拒绝覆盖，清空显示名称、短说明和默认提示词后旧值应被删除，同时保留图标、品牌色等未由当前界面管理的元数据；多个标签页同时连接时，任一页面的 Skill 变更应自动同步，断开或切换 Agent 时旧请求不得重新写回列表或弹出编辑器。
- Agent Skill 草稿生成：创建 Skill 时应提供「空白创建」「从当前对话生成草稿」「从当前画布生成草稿」三种入口；空对话不得发起生成，取消时不得写入文件，确认后才写入站点工作空间 `.agents/skills`；Agent 运行中应禁用生成，多标签页下对话和画布来源必须分别严格绑定发起请求的 `threadId` 和 `clientId`，生成期间外部 MCP 仍应操作最近聚焦页面；草稿运行时创建、启停、删除和更新 Skill 应被统一拒绝，点击停止应真实中断临时草稿 turn；草稿不得泄露本地路径、密钥、媒体数据、真实节点 ID 或任务进度等临时状态，普通中文斜杠文本与 `/imagine` 等命令必须保持完整，生成草稿使用的临时 turn 不得出现在 Agent 对话、历史或日志中。
- Agent Skill 调用：在技能页点击「使用」或在输入框输入 `/` 搜索并选择 Skill 后，Skill 应作为原子 token 插入正文，而不是显示在输入框上方；发送任务时应通过 Agent 原生结构化 Skill 输入执行，发送成功后清除选择，失败时保留；新建对话、断开连接、Skill 被停用或删除时也应清除失效选择，发送前、任务完成后和刷新历史后的用户消息文字与 token 位置应保持一致。
- Agent 输入框快捷引用：输入 `/` 后应显示已启用 Skill 列表，输入 `@` 后应显示当前画布的图片、视频、音频和文本素材，长列表使用较高的内部滚动区域；选中项应按当前光标位置插入正文，例如「这是第一张图 `@图片1` 融合第二张图 `@图片2`」，不再集中显示在输入框上方，按 `Backspace` 或 `Delete` 时应整块删除；发送时应保持原句顺序，按节点 ID 精确引用发起页面的素材，并把引用图片的实际内容交给 Agent；输入框和聊天记录都应将引用渲染为与正文基线对齐的紧凑标签，悬浮或聚焦后可预览图片、视频、音频或文本内容，不重复显示内部图片附件，切换会话或刷新后引用样式应保持；可用方向键、`Enter` 或 `Tab` 选择，`Esc` 应关闭候选菜单，候选菜单打开时回车不得误发送消息。
- Agent 消息元数据：发送包含图片附件、Skill 或画布引用的消息后，刷新当前页面、在另一页面恢复同一对话或重启 Canvas Agent，历史消息都应由 Agent 按准确的 `clientMessageId`、`threadId` 和 `turnId` 恢复展示，本地缩略图仍可悬浮或点击查看，不依赖浏览器 IndexedDB 或文本匹配；通信协议版本变化不得清空独立的消息存储，遇到未知版本或损坏清单时应拒绝写入且保留原文件；删除线程后对应缩略图和引用元数据应同时删除，不得按记录数量或文件大小静默裁剪，改动前仅存在于浏览器旧缓存中的消息继续显示普通文本且不尝试迁移。
- Agent Markdown 样式：右侧 Agent 回复中的代码块应为横向占满消息区域、无语言标题和无双层边框的紧凑代码条，单行内容不应保留纵向大面积空白，复制操作仅在悬停时弱化显示；行内代码、链接在浅色和深色主题下应清晰；点击外部链接后应显示中文紧凑确认弹窗，长路径能够正常换行且复制、继续打开和关闭操作可用；点击 `/Users/`、`/home/` 等本地绝对文件路径时应改为提示在系统文件管理器中定位，支持复制路径，且浏览器地址不应跳转为 localhost 文件路径。
- Agent 工具确认模式：右侧面板标题栏不应再显示「工具确认」开关；对话输入框左下方应显示确认模式选择，默认选中「自动确认」，画布写入工具应直接执行；切换为「手动确认」后，画布写入工具应在对话中展示等待确认卡片，并支持批准或拒绝。
- Canvas Agent Agent 升级：启动 Canvas Agent 后应输出 Canvas Agent、内置 Agent 和本机 Agent 版本，实际运行的内置 Agent 应为 0.146.0；内置与本机版本不一致、未安装本机 Agent，或 npm 存在更新版本时应显示对应升级提醒，npm 检查失败不应阻止服务启动；Agent 应能正常连接 Agent、创建或恢复会话、发送消息并调用画布工具，运行中停止任务应只中断当前 turn，随后无需重启 Agent 即可继续发送新任务。
- Canvas Agent Debug：普通启动应通过公共 logger 输出 Info、Warn 和 Error 日志；使用 `npx -y @basketikun/canvas-agent@latest --debug` 启动后还应输出 Debug 日志并显示日志文件路径，终端统一采用“`YYYY-MM-DD HH:mm:ss` 级别 消息 详情”的纯文本单行格式，`~/.infinite-canvas/logs/` 下应按启动日期生成相同格式的 `canvas-agent-YYYY-MM-DD.log`，同一天多次启动应追加到同一文件；日志中不应出现连接 token 或图片 Data URL 原文。
- Canvas Agent 凭据脱敏：Agent 与 Claude CLI 的 stderr 包含 Bearer token、`sk-` 密钥、显式 API key/token/authorization 赋值、ANSI 样式或跨输出分片的凭据时，调试日志和网页诊断事件均不应出现明文；普通 stderr 文本应保持不变。
- Canvas Agent 配置权限：在 Linux 和 macOS 上保存配置后，`~/.infinite-canvas` 权限应为 `0700`，`canvas-agent.json` 权限应为 `0600`，已有的宽松权限也应被纠正；配置应能继续正常读写，Windows 启动不受影响。
- Canvas Agent URL 自动连接（**已作废**）：这条只服务浏览器版，`#agentUrl` / `#agentToken` 连接参数已随浏览器版一起移除，桌面版改为启动时读本地 Agent 配置自动连接，无需再验收。
- 图片 API 模型参数：`gpt-image-*` 的生成和编辑请求不应发送 `response_format`，`dall-e-*` 请求仍应发送 `response_format: "b64_json"`。
- 图片外链持久化：画布和生图工作台对图片接口返回的远程 URL 应只下载一次，经图片解码校验后保存到 IndexedDB；返回 `200` 但内容不是图片时应失败，下载期间停止画布生成后不得保存或应用结果；浏览器因 CORS 无法读取但图片仍可显示时，应保留原 URL 且不生成空 `storageKey`，插件调用在外链可读取时仍应收到 Data URL。
- 多参考图编辑：OpenAI 格式在多张参考图时应使用重复的 `image[]` 表单字段提交文件，单张参考图仍使用 `image`；新建的 OpenAI 图片脚本应使用相同字段名。Gemini 渠道和已经保存的自定义脚本不受影响。
- Canvas Agent Agent 日志：Agent app-server 输出带颜色或样式控制符及 UTC 时间的 stderr 时，本地日志和网页诊断日志应只显示一份 `YYYY-MM-DD HH:mm:ss` 本地时间和干净文本，不应出现重复 ISO 时间或 `[2m`、`[31m` 等 ANSI 转义内容。
- Agent HTTP 诊断日志：网页发送一条普通消息后，本地 Debug 日志不应重复输出 `/health`、`/canvas/state`、`/canvas/activate` 成功请求、流式增量或完整会话响应，只保留 HTTP 请求与 Agent 生命周期摘要；右侧「日志」应以单行时间线展示发送、开始、回复、工具、完成用量和错误，不再输出 userMessage started/completed、流式摘要、重复 threadId 或大段原始 JSON。
- Agent 排查日志：右侧「日志」中的排查视图应显示连接摘要，并可按错误、警告和信息筛选；向下查看日志时仅列表内部滚动，标题、连接状态、筛选数量和操作按钮保持固定；连续相同事件应折叠计数，单条日志可展开查看完整详情；原始 JSON、复制全部、复制最近错误和清空功能应继续可用，浅色与深色主题下均应清晰。
- Agent 排查日志顺序与跟随：日志应按时间从旧到新排列，进入日志或切换筛选时定位到最新事件；停留底部时自动跟随新日志，展开最后一条后应继续停留在完整详情底部，向上浏览后暂停跟随并显示与对话区视觉高度一致的居中圆形向下箭头，新日志数量只在悬浮提示中显示；列表底部不应出现额外留白，点击按钮后回到底部并恢复跟随。
- Agent 对话统计：用户消息应右对齐并使用透明无气泡的简洁排版，用户和 Agent 两侧均不显示人物头像，消息下方均不显示时间或 Token 信息；输入框上方应居中展示最新一次模型调用的输入、缓存、输出 Token 用量，不显示会话累计值，数值更新时应从旧值平滑滚动到新值而非突然跳变，新建、切换或删除当前会话后应清空旧统计。
- Agent 回复实时显示：在右侧 Agent 发送消息后，用户消息下方应立即出现“正在思考...”，任务运行期间不应闪退；工具完成后应显示 Agent 正在继续处理及已等待时长，等待超过 30 秒时提示可继续等待或停止本轮；Agent 的回复应在当前对话中持续显示，实时事件缺失时也应在任务完成后自动同步完整内容，无需切换到历史或日志再返回对话。模型繁忙等任务失败时应立即结束等待状态，在对话中显示中文错误原因和重试建议，诊断日志不应再把失败轮次记为“处理完成”，刷新历史后错误仍应保留。新建尚未发送首条消息的空会话不应反复出现历史读取失败。
- Agent 对话实时与历史一致性：运行包含思考、命令及画布工具的较长任务，在执行中刷新发起页面或打开第二个页面时，已出现的用户消息、思考过程、工具卡和回复前缀均应保留并继续更新；同一思考或工具只显示一张卡片，任务结束及再次刷新后内容、顺序和状态应一致。切换页面焦点不能改变本轮画布工具目标，发起页面断开后不得把图片或写操作转交其他画布，使用相同页面身份重连后才能继续处理。
- Agent 流式交互性能：发送长回复时文字应连续平滑出现，输入框、滚动和画布操作不应随回复变长而明显卡顿；长历史会话中只有当前流式消息持续更新，屏幕外消息不应造成明显布局压力；任务完成后应通过 SSE 自动同步完整历史，不再持续请求 `/health` 轮询状态。
- Agent 过程时间线：新建 Agent 对话后 Agent 应生成可读思考摘要，并在运行时依次显示中文的思考摘要、执行计划、命令执行、网页搜索、文件修改和画布工具活动；思考摘要的图标、标题和箭头应稳定保持在同一行，默认收起且无边框，点击箭头后才展开 Agent 实际返回的具体摘要，其中 Markdown 强调、列表和代码应正确渲染而非显示原始符号，多行代码块和文本流程图应保留原始换行并允许横向滚动，完成事件不应再用「已完成分析」覆盖已经收到的摘要；同一轮连续命令应合并为显示数量的无边框折叠行，折叠时不显示命令预览，单条展开后直接显示详情，多条展开后可逐条查看工作目录、耗时、退出状态和运行输出；其他工具调用继续使用紧凑卡片排版，状态图标、标题和状态文字保持在同一行；结构化任务进度不应混在对话时间线中，而应独立放在对话区下方、Token 统计上方，支持展开和折叠，并逐项实时更新「待处理」「进行中」「已完成」状态；新任务生成时默认展开，任务结束后保留最新结果，同一计划更新不应生成重复内容；文件详情展示文件路径与新增/修改/删除动作，工具详情不应出现请求 ID、英文工具名或原始 JSON；一轮对话结束自动同步历史以及刷新页面后从历史中 resume 对话时，思考摘要、命令和工具过程记录仍应完整保留并保持相同展示。
- Agent 权限控制：输入框可选择「请求批准」「自动审查」「完全访问」；请求批准模式下，Agent 编辑工作区外文件、执行受限命令或访问网络时应在对话中显示审批卡片，支持拒绝、允许一次和本会话允许，并能依次处理多个并发请求；提交决定后卡片应保持禁用等待，只有 Agent 确认处理后才移除；等待审批时刷新页面，未处理的审批卡应自动恢复且不能让任务永久卡住；自动审查模式应仅将需要用户决定的风险操作送入审批；完全访问必须先显示风险确认，启用后可访问网络和本机文件且不再请求审批；选择应在刷新后保留。
- Agent 历史记录：点击记录卡片应直接进入对应对话，不再显示「进入」按钮；可勾选单条或全选多条记录并批量删除，删除当前对话后聊天内容应清空。
- Agent 默认新对话：每次进入任一画布并连接 Agent 后，对话区应保持空白且不自动恢复上一次会话，并在后台创建新线程、预热 MCP；需要继续旧对话时可在「历史」中主动选择恢复。
- Agent 当前画布优先：在已打开某个画布时要求 Agent 创建、修改、整理或生成内容，Agent 应直接读取并操作当前画布，不应先调用 `canvas_list_projects` 或使用 `site_navigate` 重复进入画布；只有明确要求查看或切换其他画布时才允许查询画布列表并导航。
- Agent 图片消息：发送一张或多张图片附件后，图片应紧跟用户文字并在消息右侧显示为约 40px 的紧凑缩略图，不再撑大消息区域，单击缩略图应打开大图预览，打开或关闭预览不应改变消息间距或产生额外空行；任务运行中、完成同步历史、切换页面及重新进入历史对话后都应显示浏览器本地保存的图片缩略图，不应消失或把 attachmentId、附件使用说明等内部上下文回显到用户消息中；删除历史会话后应同步清理对应缩略图。
- 画布文本复制：在 Agent 对话或节点信息详情中用鼠标选中文字后，按 `Ctrl/Cmd + C` 应复制所选文本，不应触发画布节点复制；未选中文字且焦点位于画布时，原有节点复制快捷键应保持可用。
- Agent 工作目录指令：`canvas-agent/agent-instructions.md` 应作为独立维护源；重启 Canvas Agent 后，当前工作目录应自动生成 `AGENTS.md`；新建对话发送消息时，Agent 日志中的用户消息只包含本轮请求和必要的附件上下文，不再重复整段 Infinite Canvas 前置提示词，画布及工作台工具仍可正常调用。
- 画布文本设置：文本节点的提示词面板应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留；文本模型自定义调用脚本应能读取 `reasoningEffort`，OpenAI 模板应按自动或指定档位正确组装请求。
- 生图工作台参考图：将一张或多张图片拖入参考图区域后应直接上传并显示缩略图；拖入非图片文件应忽略，拖动过程中区域应显示高亮提示，放下文件不应导致浏览器打开或替换当前页面。
- 工作台历史图片清理：生图或视频工作台生成内容后，在「我的素材」删除图片、删除画布图片节点、清空画布或删除画布，再次打开对应生成记录时，历史缩略图、结果图片和参考图仍应正常显示；删除生成记录时，其专属本地文件仍应正常清理。
- 视频创作台参考资产：将图片、MP4/MOV 视频或 MP3/WAV 音频拖入任一参考资产区域后，应按文件类型自动上传到对应列表；当前拖入区域应显示高亮提示，原有数量、大小、时长和格式限制应继续生效。
- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。
- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。
- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。
- 画布节点生成：连接文本节点后连续点击生成（包含失败重试），上游文本不应被重复追加；节点类型即生成模式，实际请求应使用该类型节点配置的模型。
- 画布多图生成：开始生成 N 张图片后应立即创建一个包含 N 个可展开槽位的图片节点，并且来源到结果只保留一条连线；生成期间空槽位应独立显示生成中或失败，任何已有图片内容的槽位都必须始终显示图片，任意图片率先成功后应立即成为主图并展示，不等待其他请求完成；收起状态应最多显示三层紧密错开的背板，避免占用过多画布空间，右上角应显示醒目的「N 张」数量提示；点击数量后，浮动工具条应暂时隐藏，各图片槽位应从当前节点向右上方整齐展开；已成功图片的「设为主图」应常驻显示，并在亮色、深色主题及不同图片背景上保持清晰；点击画布空白处应自动收起并恢复工具条。
- 画布多图主图切换：点击「设为主图」后，节点中心和当前最长边应保持不变，仅按新图片比例调整另一条边；自由变形节点应完全保持现有宽高，画布视口及左下角缩放值不应变化。
- 画布多图失败槽位：包括当前主槽位在内的每个失败槽位都应显示「重试」和「删除」；重试只更新当前槽位，已有成功主图时不得抢占主图；删除只移除当前失败槽位并同步更新图片数量。
- 画布多图尺寸调整：子图展开时开始拖动尺寸控制点，应先收起图片组一次，再正常调整根节点尺寸，不应触发 React 循环更新或应用错误页。
- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点，自动缩放不得超过 100%；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。
- 配置与用户偏好：导出 JSON 后应包含渠道、默认模型、生成偏好和 WebDAV 配置；在修改当前配置后重新导入该文件，应恢复导出时的设置，错误 JSON 文件应提示格式不正确。配置文件包含 API Key 和 WebDAV 凭据，不应公开分享。
- WebDAV 画布删除同步：将已同步到 WebDAV 的画布在本地删除后再次点「立即同步」，该画布不应从远端恢复到列表；刷新页面后再同步，已删除画布也不应回来。另一台设备新建且未删除的画布同步后仍应出现。我的资产和生成记录的删除同步不在本次范围。
- 本地存储设置：配置页应显示「本地存储」Tab，进入后只读取 `infinite-canvas` 数据库，自动统计 IndexedDB 占用、站点总占用、浏览器配额与使用率，并按对象仓库显示记录数及内容体积；新增或删除图片、音视频、生成记录后点击刷新，数据应同步变化，统计期间页面保持可操作。
- 生成提示词的文本编号：生成节点连接多个文本节点后发起生成，附加在提示词末尾的每段上游文本都应以「【文本1】」「【文本2】」开头并按连接顺序编号，编号与提示词里 `@` 引用及参考内容栏显示的一致；单段文本同样要带编号，图片、视频、音频编号不受影响。
- 局部遮罩编辑：弹窗底部应为「重置」「导出到画布」「立刻生成」；两个按钮都要求已涂抹区域并填写修改要求，「导出到画布」只写入节点和连线不发起请求，结果节点的提示词面板应预填拼好的提示词并可手动生成，「立刻生成」在写入节点后立即生成。涂抹区域并填写修改要求后确认，画布应在原图下方生成一个「遮罩标注」图片节点，内容为原图叠加半透明蓝色标注区域，颜色和透明度应与弹窗里涂抹时看到的一致；结果节点在原图右侧生成，并同时接收来自原图和遮罩标注的两条连线。请求应按普通参考图发送两张图片，提示词按「图片1 / 图片2」编号说明原图和标注区域，不再携带 mask 参数，Gemini 格式渠道也应可用；生成结果只改动标注区域，且不得残留蓝色标注。
- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Agent turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；非运行状态关闭当前页面后应回退到最近聚焦且仍连接的页面，运行中关闭发起页面则不得把操作转交其他画布，只有同一页面身份重连后才能继续；其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Agent 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Agent 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Agent 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示与日志完全相同尺寸、位置和样式的居中圆形向下箭头，新消息不强制打断阅读，对话底部不应出现额外留白，点击按钮后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧使用透明无气泡排版，AI 回复应在左侧使用无头像的开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
- Agent 命令记录：命令执行中应显示运行状态；完成后，同一轮相邻命令应合并为「已执行 N 条命令」折叠行且默认不显示原始命令，单条展开后直接显示完整详情，多条展开后可分别查看命令、输出和退出状态；对话结束或刷新后分组与记录不应消失。
- 跨域提示：生图、视频或音频请求被浏览器跨域策略拦截时，应明确提示需要通过自己的服务转发请求，不再只显示笼统的网络错误。
- 资产图片下载：我的资产中仍可预览的图片，点击「下载图片」应能保存文件；标题含中文、空格或「【】」时应沿用原标题作为文件名，无需改名；从画布刚存入、尚未刷新页面的图片也应能下载。
- 画布视频任务恢复：开始 OpenAI 风格视频生成后，视频节点应保存远端任务 ID。刷新页面后，尚未完成的视频应自动继续查询状态；若查询已停止，可点击「获取任务状态」继续用该任务 ID 拉取，直到生成成功、任务失败或查询请求报错。任务失败后，「重试」应重新发起生成而不是继续查旧任务。
## M3.2 会话 / 引用 / 痕迹 / 权限 端到端验收（待用户执行）
