# Features

The RunningHub channel supports single-image video generation with Vidu Q2 Pro Fast. Generated videos appear in the canvas node and can be played there.

## Canvas projects

- Create, rename, duplicate, delete, import, and export canvas projects.
- Persist projects locally and back up or restore via a local folder or `.intx.zip` workspace package.
- Keep viewport, background, nodes, connections, and assistant sessions with each project.

## Infinite canvas

- Pan, zoom, reset the view, select multiple nodes, copy and paste, undo and redo.
- Drag files onto the canvas and use lines, dots, or a blank background.
- Export the entire canvas or selected elements with their resources.

## Nodes and workflows

- Text, image, video, audio, and group nodes. Model, size, count, and reference settings live in each node's own prompt panel, and the node type is the generation mode.
- Connect text prompts and reference media to generation nodes.
- Generate or rewrite text, create images, edit images from references, and create videos.
- Preserve original image ratios by default and organize batch results as connected nodes.
- Record prompts, models, dimensions, quality, and references on generated nodes for retries.

## Timeline editing and MP4 export

- Open the canvas timeline to arrange successful image and video nodes as shots, reorder them, and trim their in/out points.
- Import narration or other audio into the canvas, trim it, set its timeline position, and mix multiple audio clips.
- Extract the first audio track from a video node into a WAV audio node connected to its source.
- Export H.264/AAC MP4 at 720p or 1080p and 24 or 30 fps, then save through the native file dialog.

## AI generation

- Connect to user-provided OpenAI-compatible endpoints directly from the browser.
- Configure multiple channels, fetch or enter model names, and choose default text, image, and video models.
- Support image count, aspect ratio, quality, transparent backgrounds, reasoning effort, and custom invocation scripts.
- Support OpenAI-style video endpoints.
- On Windows desktop, import a ComfyUI API-format image or video workflow in Settings, confirm its input bindings and output selection, then select it as a canvas model. INTX stores imported workflows in the application data directory.
- A standard canvas image generation can collect images from multiple selected ComfyUI output nodes in a single submission. After INTX restarts, reopen the canvas to retrieve the original task's images into the same node.

## Canvas Agent

- Desktop builds bundle Node and Canvas Agent. INTX starts it in the background, reuses an already running local Agent, and stops only the instance it started when exiting. The pinned OpenCode CLI downloads on first use through the bundled npm runtime.
- Manage local Agent Skills in a dedicated page: search, create, edit, delete, and import Markdown files; use saved Skills from the Agent composer with `/`.
- Run the local Canvas Agent and connect it to the browser over MCP without giving a web server direct access to browser state.
- Read the active canvas, selection, nodes, edges, generation status, and apply structured operations.
- Use the OpenCode agent from the browser side panel with streaming responses, history, a model picker, stop, token usage and diagnostics, `/` mentions of local Skills; the default free model needs no API key.
- Isolate active canvases and turns across multiple browser tabs.

## Plugin system

Canvas plugins can contribute node types, rendering, inspectors, serialization, migration, toolbar actions, and optional AI generation capabilities. Built-in and local plugins are managed through the canvas UI.

## Assets

- Store reusable text, image, video, and audio assets in the browser.

## Configuration and backup

- Export and import channel, model, and generation settings (API keys are excluded).
- Store application data and API credentials locally on desktop.
- Back up and restore canvases, assets, and media via a local folder or `.intx.zip` workspace package, and clean up thumbnail caches or unreferenced media.

## Current limitations

- The project is frontend-first and does not provide built-in cloud accounts or cloud storage.
- The canvas is desktop-only and does not provide a mobile layout.
- API keys remain in browser storage and requests are sent directly to configured providers.
- Production Docker static-resource paths still require broader deployment verification.
